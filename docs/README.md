# Documentation

All documents in this folder follow a single structure — five fixed sections: the reason
for the decision, the gains and trade-offs, how it works, a concrete JSON example, and a
mermaid diagram.

- **[Documentation Standard](documentation-standard.md)** — the rules, the review checklist,
  and what to do when a section does not fit.
- **[Document template](templates/document-template.md)** — copy this to start a new document.

## Layout

| Folder | Contents |
|--------|----------|
| `adr/` | Architecture decision records, `NNNN-kebab-title.md` |
| `api/` | Backend components and features |
| `web/` | Frontend components and features |
| `infra/` | Infrastructure, observability, tooling |
| `templates/` | Skeletons to copy |
